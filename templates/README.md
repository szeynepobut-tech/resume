# Project Name: [Street Souls Rescue]

## Executive Summary
[Our platform bridges the gap between public awareness and life-saving action by providing a real-time reporting system that mobilizes volunteers directly to the locations of animals in distress. By streamlining the transition from a sighting to a physical rescue, we ensure that vulnerable animals are quickly located, secured, and transitioned into care. This community-driven ecosystem fosters transparency through a public display of saved animals, proving that immediate intervention saves lives.]

## The Tech Stack
* **Streamlit**: Web interface framework.
* **Pandas**: Data manipulation and storage.
* **Streamlit-option-menu**: Sidebar navigation.
* **Streamlit-js-eval**: JavaScript integration for browser functions.

## Agile Methodology
I managed this project using an **8-day sprint** cycle. To maintain momentum, I conducted **Daily Standups** to track progress, identify blockers, and adjust my development goals for the following 24 hours.

## Technical Milestones
* **CRUD Operations**: Implemented logic to Create, Read, Update, and Delete data entries.
* **Virtual Environment**: Developed within a virtual environment to ensure isolated dependency management.
* **Deployment**: The MVP (Minimum Viable Product) was successfully deployed to the cloud.

## AI Collaboration
I utilized AI as a **Senior Engineering Partner**. It was instrumental in troubleshooting logic errors, optimizing my CRUD functions, and refactoring code for better readability and performance.

## How to Run
To run this project on your local machine, open your terminal and run the following commands:

```bash
pip install streamlit
streamlit run main.py
```
